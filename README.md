# Ekonomi-Sim-lasyonu-Demo
ekonomi simülasyonu demosu


farklı yatırım araçlarının fiyatlarını haftalık olarak önceden belirlenmiş dilim aralığında rastgele olarak değiştiren bir simülasyon demosu.

arayüzün her katmanını iç içe while döngülerine yazarak daha kolay bir arayüz kullanımı sağlamayı amaçladım. yapay zekadan sadece bazı syntax hatalarını düzeltmek için yardım aldım.

simülasyon rastgele değerlerle değiştiği için gerçekçilik payı düşük olsa da profesyonel formüller kullanılarak kolaylıkla geliştirilebilir, farklı yatırım araçları eklenebilir.
